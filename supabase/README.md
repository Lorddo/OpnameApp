# Supabase (declaratief)

- Bron van waarheid: `schemas/*.sql`
- Migraties genereren met `supabase db diff -f <naam>` (fase 1+)
- Lokaal: `supabase start` (Docker vereist)
- Remote linken: `supabase link --project-ref <SUPABASE_PROJECT_REF>`

Domeinmodel (orgs, properties, inspections, …) komt in fase 1.
